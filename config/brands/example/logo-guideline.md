# Example Cloud ロゴ ガイドライン (サンプル)

> これはブランド参照型 AI ルール (`rules/ai/logo-regulation.js`) のデモ用サンプルです。
> 実運用では自社のロゴ規定に差し替えてください。AI は本文をそのまま判定基準として読み込みます。

## アイソレーションと最小サイズ

ロゴは独立性・識別性をもって表示します。他の要素と十分な余白を確保し、視認できる最小サイズを守ってください。ここで指定する値は最低限であり、実際にはできる限り広いスペース・大きいサイズを確保してください。

### アイソレーション (クリアスペース)

- 横組みロゴ：ロゴの高さ (A) に対し、周囲へ 0.5A 以上のスペースを確保する。
- 縦組みロゴ：周囲へ 0.5A 以上のスペースを確保する。
- 指定値は最低限。可能な限り広く取る。

### 最小使用サイズ

- 横組みロゴ：高さ 60px 以上
- 縦組み／小型ロゴ：高さ 80px 以上

## カラー表示規定

- 原則、ポジティブ表示 (明るい背景に濃色ロゴ) を使用する。
- 背景が濃色の場合のみネガティブ表示 (白抜き) を使用できる。
- 使用色: ブランドプライマリ / ブラック / モノクロ。

## 禁則 (絶対 NG)

- アイソレーション基準を満たさない配置 (周辺に他要素が近接)
- 変形 (長体・平体・斜体)
- 回転・角度変更
- 影 / グラデーション等の効果付与
- 文字間の変更
- 指定色以外の色を使用
- アウトライン化して使用
- 繁雑な写真・低コントラストな背景上への配置
- サイズ比率や位置関係の編集
